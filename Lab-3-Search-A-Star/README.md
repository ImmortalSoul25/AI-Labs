# Lab 3 — Search and A*

Submission files for the warehouse robot navigation laboratory.

- search_lab.py — A*, BFS, heuristic variants, terminal path display, and automated assertions.
- REPORT.md — formulation, design, tests, BFS/A* comparison, heuristic investigation, and reflections.
- PROMPTS.md — LLM prompts used to document the implementation workflow.

## Run

Requires Python 3. No third-party packages are needed.

~~~bash
python search_lab.py
~~~

The script runs the original warehouse, adjacent-goal, no-solution, and alternative-path tests, then compares BFS/A* and heuristic variants.
